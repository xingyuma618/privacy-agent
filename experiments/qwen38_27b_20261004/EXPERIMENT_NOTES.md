# 实验记录

2026-10-04：新建独立实验，固定教师路径为 Qwen3.8-27B，学生路径为 Qwen3-4B-Instruct-2507。教师文件夹中 config 的模型结构实际声明 Qwen3_5ForConditionalGeneration；服务按该结构加载用户指定的本地权重，没有替换模型。

输入：原始 BIRD train 9,428 条、69 个数据库。未复用旧教师过滤样本或轨迹。

实现修复：树节点与 rollout 状态分离；全程外发内容累积审查；列映射以表和列为键；保留结果重复行；SQL AST 恢复引号及数值类型；工具异常及修复情况保留。7 项回归测试通过，详见 logs/regressions.log。

环境：独立 CUDA 环境，四个 TP=2 副本，8 张 A100 80GB。推理关闭 thinking，eager 模式；采样 seed 与问题、角色、调用序号绑定，配置和实际调用使用量保留。

旧轨迹不和新轨迹混合。新生成结果尚需对教师标注和隐私打分进行人工抽查。学生训练、强化学习和论文指标重测目前尚未启动。

2026-10-04 并发优化：原 8 个线程和每服务 16 条序列升级至 100 个线程和每服务 48 条序列。4 个 TP=2 副本、BF16、上下文 65,536 均保留。启用前缀缓存和 FULL_DECODE_ONLY CUDA Graph（关闭 Inductor 编译），请求超时 180→1800 秒。原数据缓存不覆盖，新运行目录 runs/full_parallel100；9 个标注、8 个 Prompt 结果、1 个 MCTS 结果按明确来源和旧指纹复用，内容核对一致；未完成搜索重启。

压测数据仅验证吞吐，不混入训练数据。原 eager 服务，8 并发：106 输出 token/s；优化后，8/32/100 并发短输出压测：171/1081/2142 输出 token/s。长输入压测每请求 4264 输入 token、512 输出 token，32/100 并发：1256/3166 输出 token/s；100/100 请求成功，未观察到 API 错误。共享前缀、固定输出的压测不能直接作为实际 MCTS 耗时缩短比例。详细数值见 runs/benchmark_*.json，真实合成观测见 runs/throughput_real_100.json。

100 线程恢复后真实任务观测：约 110 秒窗口内，平均输出吞吐 2,384 token/s；最高 107 条生成序列同时运行（包含 n=3 分支），最大等待队列 0，KV 缓存最高约 18.8%，缓存抢占 0。窗口结束时已新增 22 条 Prompt 完成结果，未观察到基础设施错误。该短窗口不代表整个数据集的长期吞吐，后续应以完整问题吞吐和平均 MCTS 模拟次数重新估算 ETA。

SGLang 对比（2026-10-04）：在隔离环境安装 SGLang 0.5.10、torch 2.9.1+cu128，并于 /tmp 补齐 NVIDIA CUDA 12.8 编译器和开发头文件。使用相同 GPU 0、1、相同本地 BF16 权重、TP=2、上下文 65,536、关闭 thinking；每组预热后测 96 条请求，每条 4,264 输入 token、固定 512 输出 token。25 并发 vLLM/SGLang 为 781.9/763.9 输出 token/s；48 并发为 1337.0/1294.3。四组均全部成功。JSON 和 n=3 工具调用验证通过。SGLang 的 extra_buffer 重叠配置曾在工具请求上停滞；有效结果来自 no_buffer＋禁用自定义 all-reduce 的兼容配置。该轮仅一次测量，小差距不能证明普遍快慢；不显示迁移收益，保留现有 vLLM。

测试期间合成进程使用 SIGSTOP 暂挂，搜索树及线程状态保留在 RAM；测试后 SIGCONT 恢复。未把压测或 SGLang API 冒烟样本加入训练数据。暂停起止见 runs/backend_test_state.json；跨越暂停的样本及调用 seconds 包含暂停时间，后续成本/ETA 统计应单独处理这段空档。完整比较见 runs/sglang_comparison.json。
